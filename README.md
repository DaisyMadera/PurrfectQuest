# Purrfect Quest

Purrfect Quest is a team-developed 2D adventure game created with Unity and C#. Guide a cat through a house and garden while avoiding hazards and enemies as it searches for its owner.

## Gameplay

- Explore house and garden environments.
- Avoid hazards and enemies.
- Play through scenes built in Unity.

## Built With

- Unity 2022.3 LTS
- C#
